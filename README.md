# Java 프로그래밍

Java 프로그래밍(LAB) 과목의 주차별 실습, 시험 대비 코드, 게임 제작 과제 백업입니다. Eclipse 프로젝트 형태로 저장되어 있습니다.

| 폴더 | 내용 |
|---|---|
| `1주차` ~ `14주차` | 주차별 실습 코드와 LAB 보고서(`.docx`) |
| `기말`, `시험` | 클래스, 패키지, 큐 등 시험 대비 실습 |
| `게임 제작/` | 게임 과제 초기 버전 (`GAME/src/game/Game.java`, `Script.java`) |
| `게임 제작2/` | 2D 타일 기반 게임 (Java 파일 27개: `Entity/Player`, `Monster/MON_Ghost`, `MON_TreeMonster`, `Object/`, `Tile/`, `Dialogue/`) |

게임 플레이 영상은 Google Drive에 있습니다.
https://drive.google.com/drive/folders/16AZ4glfLzDJJG9SR9xgpbmN-65NkiXx1?usp=drive_link
